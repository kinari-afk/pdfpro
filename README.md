# Webリンク抽出 & ファイルダウンローダー

指定したWebページからリンク（`<a href="...">`）を抽出し、選択したリンク先ファイルをまとめてダウンロードできるデスクトップアプリです。

## 必要環境

- Python 3.11 以上（`tkinter` が利用可能な環境）

## 実行方法

```bash
python app.py
```

## 使い方

1. `対象URL` にリンク抽出したいWebページのURLを入力
2. `リンク抽出` をクリック
3. 一覧からダウンロードしたいリンクを選択（Ctrl / Shift で複数選択可）
4. 必要に応じて `保存先` を変更
5. `選択リンクをダウンロード` をクリック

## 補足

- 相対URLは自動で絶対URLに変換して一覧表示します。
- 同名ファイルが保存先にある場合、`_1`, `_2` ... を付けて保存します。
